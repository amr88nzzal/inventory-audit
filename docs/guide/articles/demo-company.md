**متى أحتاج هذا؟** عندما تريد تجربة النظام أو عرضه على مستخدم محتمل دون أي بيانات حقيقية.

> **حالة الشاشات:** الواجهة (المرحلة 5) لم تُبنَ بعد، فالتجربة الآن عبر الـ API فقط. يُحدَّث هذا المقال بلقطات الشاشات عند بنائها.

## بيانات الدخول

- **رمز الشركة:** `demo`
- **كلمة المرور لكل الحسابات:** `Demo-Inventory-2026`

| اسم المستخدم      | الدور       | ماذا يستطيع الآن    |
| ----------------- | ----------- | ------------------- |
| `demo.admin`      | مدير الشركة | كل شيء              |
| `demo.supervisor` | مشرف جرد    | الاطلاع على الأدوار |
| `demo.auditor1`   | موظف جرد    | لا صلاحيات إدارية   |
| `demo.auditor2`   | موظف جرد    | لا صلاحيات إدارية   |

## الخطوات

1. سجّل الدخول برمز الشركة `demo` وأحد الحسابات أعلاه (انظر مقال «تسجيل الدخول»).
2. جرّب بحرية: أنشئ أدواراً أو غيّر صلاحياتها؛ لا شيء هنا حقيقي.
3. قبل كل عرض، اطلب من مدير المشروع إعادة الضبط ليعود كل شيء نظيفاً.

## ملاحظات

- الشركة التجريبية مميّزة في النظام (`is_demo`) ولا يمكن لأي مستخدم تغيير هذه العلامة.
- كلمة المرور معروفة عمداً؛ **لا تُدخل أي بيانات حقيقية** فيها أبداً.
- كل مرحلة جديدة تضيف بياناتها التجريبية (مستودعات، أصناف، مهام جرد) إلى هذه الشركة.
- لمدير المشروع: `node dist/cli.js seed-demo` ينشئها أو يكمل ما ينقص، و`reset-demo` يعيدها نظيفة (انظر RUNBOOK).
