# دليل المستخدم — كيف يُحرَّر

مقالات Markdown في `articles/` (المصدر الوحيد). لكل ميزة يراها المستخدم مقال واحد: مهمة واحدة بعنوان فعل، خطوات مرقّمة بأسماء الشاشات كما تظهر حرفياً، وملاحظات في النهاية. انسخ `TEMPLATE.md`؛ الأدوار: `admin` أدمن الشركة، `platform` مدير المنصة، `auditor` موظف الجرد. لا بيانات حقيقية في اللقطات.
