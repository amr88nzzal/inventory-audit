# دليل المستخدم — كيف يُحرَّر

مقالات Markdown في `articles/` (المصدر الوحيد). لكل ميزة يراها المستخدم مقال واحد: مهمة واحدة بعنوان فعل، خطوات مرقّمة بأسماء الشاشات كما تظهر حرفياً، وملاحظات في النهاية. انسخ `TEMPLATE.md`؛ الأدوار: `admin` أدمن الشركة، `platform` مدير المنصة، `auditor` موظف الجرد. لا بيانات حقيقية في اللقطات.

- **الواجهة:** تُبنى مع الويب (المرحلة 5) وتقرأ هذه المقالات نفسها؛ حتى ذلك الحين تُقرأ كملفات.
- **تحديث مع كل خطوة:** كل PR يضيف ميزة يراها المستخدم يضيف مقاله أو يحدّث مقاله، ويُحدَّث `status` من `api-only` إلى `ready` حين تتوفر الشاشة.
- **الشركة التجريبية:** [`demo-company.md`](articles/demo-company.md) تحوي حساباتها؛ كل مرحلة تضيف بياناتها التجريبية.
- حقول الترويسة المطلوبة: `title` و`summary` و`roles` و`order` و`status` (`api-only` أو `ready`)، ويتحقق منها اختبار وحدة.
