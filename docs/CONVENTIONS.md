# معايير المشروع — Conventions

مأخوذة من معايير HRMS ومكيَّفة للجرد. التعارض مع طلب صريح من عمرو: طلبه يغلب.
Adapted from the HRMS conventions. An explicit request from Amro overrides this file.

## 1. الكود

1. TypeScript `strict`؛ دوال arrow فقط (`func-style: expression`)؛ بلا `export default`.
2. حدود الوحدات: لا استيراد من وحدة أخرى إلا عبر `index.ts` (يفرضه ESLint).
3. التعليقات: سطر بالعربية وسطر بالإنجليزية، وتشرح «لماذا» لا «ماذا».
4. `snake_case` في القاعدة و`camelCase` في الكود؛ معرّفات UUIDv7.
5. الكميات الكسرية والمبالغ: `decimal.js` ونصوص عشرية في الـ API، لا `number`.

## 2. قاعدة البيانات

1. كل جدول يخص الشركة: `company_id` + RLS `tenant_isolation` (`ENABLE` + `FORCE`).
2. أعمدة مشتركة: `created_at, updated_at, created_by, updated_by, deleted_at`؛ حذف ناعم بفهارس جزئية.
3. تهجيرات `<timestamp>_description.sql` لا تُعدَّل بعد دمجها؛ التغيير بتهجيرة جديدة (Expand → Contract).
4. `audit_records` للإضافة فقط؛ التصحيح بسجل جديد.
5. كل وصول للبيانات عبر `ctx.trx` من `withTenant`.

## 3. الـ API

1. تحت `/api/v1`؛ استجابة `{ data, meta }`؛ أخطاء `{ error: { code, status, message, details, requestId } }` عبر `AppError`.
2. Zod لكل مدخل في `packages/shared`، والفلاتر بقائمة بيضاء، وترقيم الصفحات من الخادم (الافتراضي 25، الأقصى 100).
3. سجل خارج نطاق المستخدم → 404؛ غياب الصلاحية → 403؛ تجاهل أي `companyId` من العميل.
4. العمليات الحرجة بترويسة `Idempotency-Key`؛ القفل المتفائل بعمود `version` و`VERSION_CONFLICT`.
5. صلاحيات `الوحدة.المورد.الفعل`؛ الصلاحية الجديدة تحتاج منحاً للأدوار القائمة (تُذكر في الـ PR).

## 4. الاختبارات

1. وحدة للدوال النقية؛ تكامل على PostgreSQL حقيقي بشركتين لكل ميزة (403/404، المسار السعيد، الحدود، العزل).
2. **اختبار الطفرات** (mutation check): نكسر الكود عمداً للتأكد أن الاختبار يفشل، ونذكر النتيجة في الـ PR.
3. لا PR يغيّر منطقاً دون اختبار.

## 5. Git

1. Trunk-based: فرع `claude/<موضوع>` قصير، PR صغير واحد إلى `main`، Conventional Commits.
2. فحوص CI: `verify` و`integration` و`docker` (و`a11y` عند وجود الويب).
3. قبل الدفع: `pnpm format`، `pnpm lint`، `pnpm typecheck`، الاختبارات.
4. PRs المتراكمة (stacked): يُعاد توجيه القاعدة إلى `main` بعد دمج السابق.
